FINALLY WORKED: `node node_modules/playwright/cli.js install-deps chromium` from the existing Playwright installation exited 0. Chromium 156 launches at the default executable path without sourcing the stale environment script; no repository package added.
- DIDN'T WORK: the new unit test sliced rail CSS at the nested `.sidebar-header`, causing `the rail toggle is a 44px target` to fail. FINALLY WORKED: delimit at the top-level newline-prefixed selector; assertion now reads the full desktop-only rule.
- DIDN'T WORK: the verification script waited for five cards after reloading a narrowed board and hit `page.waitForFunction: Timeout 10000ms exceeded`. FINALLY WORKED: wait for a nonempty rendered canvas, then assert filters and return-view values explicitly; a filtered fixture legitimately has fewer than five cards.
- DIDN'T WORK: raw `scrollWidth` treated the intentional outboard connection ports as `titles16pxNoOverflow: false`. FINALLY WORKED: measure title overflow and in-flow child bounds separately, preserving the 7px connection ports while requiring all title/content blocks to stay inside the card.
- DIDN'T WORK: staging the typecheck log exposed npm's trailing blank line (`logs/typecheck.log:4: new blank line at EOF.`) in `git diff --cached --check`. FINALLY WORKED: remove that single trailing empty line from the captured log; command output and result remain unchanged.
